1/5
A 3D edit can look convincing until you move the camera. Fill a hole independently in several views and you may get several plausible answers that don't describe the same scene.

2/5
WINGS (Sep 29) completes masked Gaussian-splat regions using a 3D-native prior. The paper evaluates 29 scenes. Alignment, view-dependent appearance and runtime still matter.
https://arxiv.org/abs/2609.37816v1

3/5
The useful question: what does sharing one 3D representation actually buy you? Rotate the camera. A shared shape projects differently, but it doesn't need to be reinvented for each view.

4/5
This week's interactive uses a synthetic scene. Change opacity and Gaussian shape; inspect the projected ellipses. One panel deliberately changes its repair with the view. It's a teaching comparison, not WINGS output.

5/5
A consistent repair can still be wrong. Try the orbit, then lower the opacity to see what's overlapping. PNG and GIF exports are built in; a ready MP4 comes with the kit.
https://kavehkamali.github.io/frontier-fieldnotes/gaussian.html
